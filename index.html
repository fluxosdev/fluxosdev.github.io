About

A small OS with a big personality.

fluxOS is an operating system built from the ground up to be simple, fast and fun to use. It ships with a familiar desktop, a built-in web browser, a terminal, a file manager and a few classic apps, all running in a compact, hackable system.

Features

Everything you need, nothing you don't.

🖥️

Familiar desktop

Draggable windows, a taskbar, a start menu and desktop icons that feel right at home.

🌐

Web browser

Browse the modern web, with encrypted TLS 1.3 connections.

⌨️

Terminal

A built-in terminal for tinkering, scripting and getting under the hood.

🎮

Runs classics

Launch DOS-era games like DOOM, and run 3D-accelerated demos such as 3D Gears.

📁

File manager

Browse drives and CD-ROMs, and launch programs with a double-click.

⚡

Lightweight

Small footprint and quick to boot, even on modest hardware or in a VM.
